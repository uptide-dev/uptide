`fix` gets the assisted Stripe migration through on real repositories. The guide suggests the import the way the file's neighbours write theirs (a tsconfig `paths` alias such as `@/lib/stripe`, else an extensionless relative path; `.js`/`.ts` only where the repository already uses them), and no longer requires one spelling. A pre-existing error that an added import moves down a line is matched to itself, not reported as new. Sites of the same change in one file go to the agent as one task, with every enclosing function shown, and are accepted together. Jest related-tests runs pass the affected files before `--testPathIgnorePatterns`, which swallowed them; when a related-tests run fails before any test, or finds none, the repository's own suite runs and the report shows the scoped command and its output. Reports print the published CLI version instead of 0.1.0.
